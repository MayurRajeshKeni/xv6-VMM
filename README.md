## Project Overview
This project modifies the standard xv6 operating system to support virtual memory swapping (Demand Paging). 

## Build Instructions
To compile and boot the kernel, run:
* `make qemu` (Opens in a new QEMU window)
* `make qemu-nox` (Runs directly in the terminal)
